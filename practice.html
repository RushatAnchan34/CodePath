01. Add Two Numbers

Write a C program to accept two integers from the user and display their sum.

Example

Input

10
20

Output

Sum = 30

Explanation

In this problem, you need to:

  1. Accept two integer values.
  2. Add both numbers.
  3. Display their sum.

Requirements

  • Use the int data type.
  • Accept input using scanf().
  • Display the result using printf().
