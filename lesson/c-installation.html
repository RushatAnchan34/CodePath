Lesson 3

Installing a C Compiler

1. What is a Compiler?

A Compiler is a software tool that translates source code written in a programming language into a form that the computer can execute.

In C programming, GCC is a popular compiler used to compile C programs.

2. What is GCC?

GCC stands for GNU Compiler Colloection. It supports programming languages such as C and C++.

3. What Do We Need?

  • A computer/
  • A text editor such as Visual Studio Code, CodeBlocks and many more.
  • A C compiler such as GCC.

4. Installing GCC on Windows

One way to install GCC on Windows is through MSYS2. MSYS2 provides a package manager that helps install development tools.

Step 1: Download MSYS2

Visit the official MSYS2 website and download its installer.

Visit MSYS2 Official Website

Step 2: Install MSYS2

Run the installwe and follow the installation instructions. The default installation location is recommended.

Step 3: Open UCRT64 Terminal

After installation, open the MSYS2 UCRT64 terminal from the Windows Start menu.

Step 4: Install GCC

Enter the following command in the UCRT64 terminal: 

pacman -S mingw-w64-ucrt-x86_64-gcc

Step 5: Verify Installation

Enter this command to check whether GCC is installed: 

gcc --version

If the compiler version appears, GCC is installed.

5. Important Terms

  • Compiler: Translates source code.
  • GCC: GNU Compiler Colloection.
  • IDE: An enviroment for writing and developing programs.
  • Source Code: instructions written by a programmer.
