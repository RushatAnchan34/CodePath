Lesson 4

Your First C Program

Welcome to your first practical C programming lesson! In this lesson, you will write and understand your first C program.

1. Writing Your First Program

Let's start with a simple program that displays Hello, World! on the screen. 

            #include <stdio.h>
            int main() {
                printf("Hello, World!");
                return 0;
            }

2. Understanding the program

#include <stdio.h>

This is a preprocessor directive. It includes the Standard Input Output header file. which provides functions such as printf() and scanf().

int main()

The main() function is the entry point of a C program. Program execution begins from this function.

printf()

The printf() function displays output on the screen.

return 0

This indicates that the main() function has finished successfully.

3. Program Output

When you exxecute the program, you get:

Hello, World!

4. Important Rules in C

  • C is case-sensitive.
  • Most statements end with a semicolon (;).
  • Curly braces {} define a block of code.
  • Every executable C program needs a main() function.
