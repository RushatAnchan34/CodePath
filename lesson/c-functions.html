Lesson 10

Functions in C

Learn how to create and use functions to organize, reuse, and simplify your C programs.

1. What is a Function?

A function is a block of code that performs a specific task. Instead of writing the same code repeatedly, we can create a function and call it whenever needed.

For example, we can create a function to add two numbers. Whenever we need to perform addition, we can call that function.

Example:

#include <stdio.h>

void greet() {
    printf("Welcome to CodePath!");
}

int main() {
    greet();
    return 0;
}

Output:

Welcome to CodePath!

Here, greet() is a function. We call it inside the main() function.

2. Why Do We Use Functions?

Functions provide several advantages:

  • Code Reusability: We can use the same function multiple times.
  • Easy Maintenance: We can modify a function without changing the entire program.
  • Code Organization: Large programs can be divided into smaller parts.
  • Readability: Functions make programs easier to understand.

3. Three Important Parts of a Function

In C, working with a function generally involves three important parts.

A. Function Declaration

A function declaration tells the compiler about the function's name, return type, and parameters. 

int add(int a, int b);

B. Function Definition

A function definition contains the actual instructions that the function performs. 

int add(int a, int b) {
    return a + b;
}

C. Function Call

A function call executes the function. 

int result = add(10, 20);

4. Complete Function Example

#include <stdio.h>

int add(int a, int b);

int main() {
    int result = add(10, 20);
    printf("Sum = %d", result);
    return 0;
}

int add(int a, int b) {
    return a + b;
}

Output:

Sum = 30

Let's understand the important parts:

  • int add(int a, int b); declares the function.
  • add(10, 20) calls the function.
  • a and b are parameters.
  • 10 and 20 are arguments.
  • return a + b; sends the result back.

5. Parameters and Arguments

Parameters and arguments are related, but they are not exactly the same.

  • Parameters: Variables mentioned in the function definition.
  • Arguments: Actual values passed when calling the function.
#include <stdio.h>

void display(int number) {
    printf("Number = %d", number);
}

int main() {
    display(50);
    return 0;
}

Output:

Number = 50

Here, number is the parameter and 50 is the argument.

6. Return Values

A return value is the result sent back by a function to the part of the program that called it.

The return type tells us what kind of value a function returns. 

#include <stdio.h>

float calculateArea(float radius) {
    return 3.14 * radius * radius;
}

int main() {
    float area = calculateArea(5);
    printf("Area = %.2f", area);
    return 0;
}

Output:

Area = 78.50

The function returns a floating-point value, which is stored in the area variable.

7. What is the void Keyword?

The void keyword indicates that a function does not return a value. 

#include <stdio.h>

void welcome() {
    printf("Welcome to C Programming!");
}

int main() {
    welcome();
    return 0;
}

Output:

Welcome to C Programming!

Here, welcome() displays a message but does not return any value.

8. Common Types of Functions

Functions are commonly classified into four categories based on their arguments and return values.

1. No Arguments and No Return Value

void display() {
    printf("Hello!");
}

2. Arguments and No Return Value

void display(int number) {
    printf("%d", number);
}

3. No Arguments but Returns a Value

int getNumber() {
    return 100;
}

4. Arguments and Returns a Value

int add(int a, int b) {
    return a + b;
}

9. Local Variables in Functions

A local variable is a variable declared inside a function or block. It can normally be accessed only within that function or block. 

#include <stdio.h>

void display() {
    int number = 100;
    printf("Number = %d", number);
}

int main() {
    display();
    return 0;
}

Output:

Number = 100

The variable number is local to display(). We cannot directly access it inside main().

10. Introduction to Recursion

Recursion is a programming technique in which a function calls itself.

Every recursive function needs a stopping condition, called a base case. Without it, the function may keep calling itself. 

#include <stdio.h>

void countDown(int number) {
    if (number == 0) {
        return;
    }
    printf("%d\n", number);
    countDown(number - 1);
}

int main() {
    countDown(5);
    return 0;
}

Output:

5
4
3
2
1

The function calls itself with a smaller number until it reaches zero. At zero, the base case stops the recursion.
