Lesson 7

Input and Output in C

Input and output operations allow users to interact with a program. In this lesson, you will learn how at accept information and display results in C.

1. What is Input and Output?

Input: Information provided to a program by user.

Output: Information displayed by a program after processing.

C provides functions such as printf() and scanf() for basic input and output operations.

2. The printf() Function

The printf() function is used to display text, numbers and other information on the screen.

Example: 


            #include <stdio.h>
            int main() {
                printf("Welcome to CodePath!");
                return 0;
            }

Output:

Welcome to CodePath!

3. The scanf() Function

The scanf() function is used to accept input from the user.

Example:


            #include <stdio.h>
            int main() {
                int age;
                printf("Enter your age: ");
                scanf("&d", &age);

                printf("Your age is %d", age);
                return 0;
            }

Example Output:

Enter your age: 20
Your age is 20

Here, %d specifies an integer and &age provides the address of the age variable to scanf().

4. Taking Multiple Inputs

We can accept multiple values using a single scanf() statement.

Example: 


            #include <stdio.h>
            int main() {
                int a, b;
                printf("Enter two numbers: ");
                scanf("%d %d", &a, &b);

                printf("First number: %d\n", a);
                printf("Second number: %d", b);
                return 0;
            }

Example output:

Enter two numbers: 10 20
First number: 10
Second number: 20

5. Format Specifiers

Format specifiers tell printf() and scanf() what type of data is being handled.

  • %d - Integer (int)
  • %c - Character (char)
  • %f - Floating-point value (float)
  • %lf - Double when using scanf()
  • %s - String (character array)
  • %u - Unsigned integer

Note: In printf(), %f is used to display both float and double values.

Example: 


            #include <stdio.h>
            int main() {
                int age;
                float marks = 85.5f;
                char grade = 'A';

                printf("Age: %d\n", age);
                printf("Marks: %f\n", marks);
                printf("Grade: %c", grade);
                return 0;
            }

Output:

Age: 20
Marks: 85.50000
Grade: A

6. Escape Sequences

Escape sequences are special character combinations used inside strings to control formatting.

  • \n - Moves the cursor to a new line.
  • \t - Inserts a horizontal tab.
  • \\ - Displays a backslash.
  • \" - Displays a double quotation mark.

Example:


            #include <stdio.h>
            int main() {
                printf("Hello\nWorld!");
                printf("\nName:\tStudent");
                return 0;
            }

Output:

Hello
World!
Name:   Student

7. Taking Character Input

We can use scanf() with %c to accept a single character from the user.

Example:


            #include <stdio.h>
            int main() {
                char grade;
                printf("Enter your grade: ");
                scanf("%c", &grade);

                printf("Your grade is %c", grade);
                return 0;
            }

The space before %c tells scanf() to skip whitespace characters such as spaces and newlines.

8. Try It Yourself

  • The first number.
  • The second number.
  • Their sum.
  • Their product.

Use scanf() to accept input and printf() to display the results.
