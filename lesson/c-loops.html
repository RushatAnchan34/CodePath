LESSON 09

Loops in C

Loops are used to execute a block of code repeatedly while a particular condition is satisfied. In this lesson, you will learn the different types of loops available in C.

1. What are Loops?

A loop is a programming structure that repeats a set of instructions until a specified condition becomes false.

For example, if you want to print numbers from 1 to 5, you can use a loop instead of writing five separate printf() statements.

2. Types of Loops in C

C provides three main types of loops:

  • for loop
  • while loop
  • do-while loop

3. The for Loop

A for loop is commonly used when you know how many times you want to repeat a block of code.

Syntax:

for (initialization; condition; update) {

        // Code to execute

    }

Example:


            #include <stdio.h>
            int main() {
                for (int i = 1; i <= 5; i++) {
                    printf("%d\n", i);
                }
                return 0;
            }

Output:

1
2
3
4
5

Understanding the for loop:

  • int i = 1: Initializes the variable.
  • i <= 5: Checks the condition.
  • i++: Increases the variable by one.

4. The while Loop

A while loop executes a block of code as long as its condition remains true.

Syntax:


            while (condition) {
            // Code to execute
            }

Example:


            #include <stdio.h>
            int main() {
                int i = 1;
                while (i <= 5) {
                    printf("%d\n", i);
                    i++;
                }
                return 0;
            }

Output:

1
2
3
4
5

Remember to update the loop variable. Otherwise, the condition may remain true forever, creating an infinite loop.

5. The do-while Loop

A do-while loop executes its code block at least once before checking the condition.

Syntax:


            do {
                // Code to execute
            } while (condition);

Example:


            #include <stdio.h>
            int main() {
                int i = 1;
                do {
                    printf("%d\n", i);
                    i++;
                } while (i <= 5);
                return 0;
            }

Output:

1
2
3
4
5

6. Difference Between for, while and do-while

  • for: Useful when the number of repetitions is known.
  • while: Useful when repetition depends on a condition.
  • do-while: Executes the code at least once before checking the condition.

7. Nested Loops

A nested loop means placing one loop inside another loop. It is useful for working with patterns, tables and multidimensional data.

Example:


            #include <stdio.h>

            int main() {
                for(int i = 1; i <= 3; i++){
                    for(int j = 1; j <= 3; j++){
                        printf("* ");
                    }
                    printf("\n");
                }
                return 0;
            }

Output:

* * *
* * *
* * *

8. The break Statement

The break statement is used to terminate a loopimmediately.

Example:


            #include <stdio.h>
            int main() {

            for (int i = 1; i <= 5; i++) {
                if (i == 3) {
                        break;
                    }
                    printf("%d\n", i);
                }
                return 0;
            }

Output:

1
2

9. The continue Statement

The continue statement skips the remaining statements in the current loop iteration and moves to the next iteration.

Example:


            #include <stdio.h>
            int main() {

            for (int i = 1; i <= 5; i++) {
                if (i == 3) {
                    continue;
                    }
                    printf("%d\n", i);
                }
                return 0;
            }

Output:

1
2
4
5
