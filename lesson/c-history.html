Lesson 2

History and Features of C

1. History of C

C was developed by Dennis Ritchie at Bell Laboratories in the early 1970s.

It was created to develop the UNIX operating system and become one of the most influential programming languages.

2. Important Features of C

Simple

C has a relatively small set of keywords and a clear syntax.

Portable

C programs can be adapted to different computer platforms.

Structured

Programs can be divided into smaller functions.

Fast

C is known for its efficient execution.

Middle-level language

C provides features useful for both system-level and application-level programming.

3. Applications of C

  • Operating systems
  • Embedded systems
  • Compilers
  • Device drivers
  • System utilities
