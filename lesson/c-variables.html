Lesson 5

Variables and Data Types

In this lesson, you will learn how to store information in a C program using variables and data types.

1. What is a Variable?

A variable is a named storage location in memory that holds a value which a program can use.

Example: 

int age = 20;

Here:

  • int specifies the data type.
  • age is the variable name.
  • 20 is the value stored in the variable.

2. Rules for Naming Variables

Follow these rules when naming variables in C:

  • A variable name can contain letters, digits and underscores.
  • It cannot begin with a digit.
  • Spaces are not allowed.
  • C keywords cannot be used as variable names.
  • Variable names are case-sensitive.

Valid examples: 


            int age;
            int student_marks;
            int number1;

Invalid examples: 


            int 1number;
            int student marks;
            int float;

3. What are Data Types?

A data type specifies what kind of value a variable can store.

Common Data Types in C

  • int: Stores whole numbers.
  • char: Stores a single character.
  • float: Stores decimal numbers
  • double: Stores decimal numbers with greater precision than float.

Examples:


            int age = 20;
            char grade = 'A';
            float price = 99.50f;
            double salary = 25000.75;

4. Displaying Variable Values

We use the printf() function to display variable values. Different data types use different format specifiers.

  • %d - int
  • %c - char
  • %f - float
  • %f - double in printf()

Example: 


            #include <stdio.h>
            int main() {
                int age = 20;
                char grade = 'A';
                float marks = 85.5f;

                printf("Age: %d\n", age);
                printf("Grade: %c\n", grade);
                printf("Marks: %f\n", marks);

                return 0;
            }

Output:


            Age: 20
            Grade: A
            Marks: 85.50000

5. Taking Input from the User

We can use scanf() to accept input from the user. The address operator (&) is used to provide the variable's address.

Example: 


            #include <stdio.h>
            int main() {
                int age;
                printf("Enter your age: ");
                scanf("%d", &age);

                printf("Your age is %d", age);
                return 0;
            }

Example output: 


            Enter your age: 20
            Your age is 20

6. What are Constants?

A constant is a value that should not be changed during normal program execution.

We can use he const keyowrd to declare a constant.


            #include ⁢stdio.h>
            int main() {
                const float PI = 3.14f;
                printf("Value of PI: %f", PI);
                return 0;
            }

Output:

Value of PI: 3.140000
