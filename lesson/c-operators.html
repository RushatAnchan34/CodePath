Lesson 6

Operators in C

Operators are symbols used to perform operations on variables and values. In this lesson, you will learn the different types of operators in C.

1. Arithmethic Operators

Arithmethic operators are used to perform mathematical Calculations.

  • + Addition
  • - Subtraction
  • * Multiplication
  • / Division
  • % Modulus (remainder)

Example: 


            #include <stdio.h>
            int main() {
                int a = 10;
                int b = 3;

                printf("Addition: %d\n", a + b);
                printf("Subtraction: %d\n", a - b);
                printf("Multiplication: %d\n", a * b);
                printf("Division: %d\n", a / b);
                printf("Remainder: %d\n", a % b);
                return 0;
            }

Output:


            Addion: 13
            Subtraction: 7
            Multiplication: 30
            Division: 3
            Remainder: 1

Important: When both operands are integers. integer division discards the fractional part. For example, 10 / 3 gives 3.

2. Relational Operators

Relational operators compare two values. The result is either true (1) or false (0) in C.

  • ==Equal to
  • !=Not equal to
  • >Greater than
  • >=Greater than or equal to
  • <Less than
  • <=Less than or equal to

Example: 


            #include <stdio.h>
            int main() {
                int a = 10;
                int b = 5;
                printf("%d\n", a > b);
                printf("%d\n", a == b);
                printf("%d\n", a != b);
                return 0;
            }

Output: 


            1
            0
            1

3. Logical Operators

Logical operators are used to combine or reverse conditions.

  • && Logical AND
  • || Logical OR
  • ! Logical NOT

Example: 


            #include <stdio.h>
            int main() {
                int age = 20;

                printf("%d\n", age >= 18 && age <= 60);
                printf("%d\n", age >= 18 || age <= 60);
                printf("%d\n", !(age >= 18));
                return 0;
            }

Output: 


            1
            0
            0

4. Assignment Operators

Assignment operators are used to assign values to variables or update their values.

  • = Assign
  • += Add and assign
  • -= Subtract and assign
  • *= Multiply and assign
  • /= Divide and assign
  • %= Modulus and assign

Example: 


            #include <stdio.h>
            int main() {
                int number = 10;
                number += 5;
                printf("Result: %d", number);
                return 0;
            }

Output:

Result: 15

Here, number += 5 is equivalent to number = number + 5.

5. Increament and Decrement Operators

These operators increase or decrease a variable's value by one.

  • ++ Increment
  • -- Decrement

Example: 


            #include <stdio.h>
            int main() {
                int number = 5;
                number++;
                printf("After increment: %d\n", number);
                number--
                printf("After decrement: %d", number);
                return 0;
            }

Output:


            After increment: 6
            After decrement: 5

6. Operator Precedence

Operator precedence determines which operation is performed first in an expression.

Example: 

int result = 10 + 5 * 2

Multiplication is performed before addition.

Result:

20

Parentheses can be used to control the order of operations. 

int result = (10 + 5) * 2;

Result:

30
