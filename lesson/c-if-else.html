Lesson 8

Conditional statements in C

Conditional statements allow a program to make decisions based on different conditions. In this lesson, you will learn how to control the flow of a C program.

1. What are Conditional Statements?

Conditional statements are used to execute different blocks of code depending on whether a condition is true or false.

For example, a program can check whether a student has passed or failed an examination.

2. The if Statement

The if statement executes a block of code only when the given condition is true.

Syntax:


            if (condition){
                //Code to execute
            }

Example:


            #include <stdio.h>
            int main() {
                int age = 20;
                if (age >= 18){
                    printf("You are eligible.");
                }
                return 0;
            }

Output:

You are eligible.

3. The if-else Statement

The if-else statement executes one block when the condition is true and another block when it is false.

Syntax:


            if (condition){
                //Executes when statement is true
            } else {
                //Executes when statement is false
            }

Example:


            #include <stdio.h>
            int main() {
                int number = 7;
                if (number % 2 == 0){
                    printf("Even number");
                } else {
                    printf("Odd number");
                }
                return 0;
            }

Output:

Odd number

4. The else-if Ladder

An else-if ladder is used when we need to check multiple conditions.

Syntax:


            if (condition1){
                //First Block
            } else if(condition2){
                //Second Block
            } else if(condition3){
                //Third Block
            } else {
                //Default Block
            }

Example:


            #include <stdio.h>
            int main() {
                int marks = 85;
                if(marks >= 90){
                    printf("Grade A");
                } else if(marks >= 75){
                    printf("Grade B");
                } else if(marks >= 50){
                    printf("Grade C");
                } else {
                    printf("Fail");
                }
                return 0;
            }

Output:

Grade B

The conditions are checked from top to bottom. Once a condition is true, its block executes and the remaining conditions are skipped.

5. Nested if Statement

A nested if statement means placing one if statement inside another if statement.

Example:


            #include <stdio.h>
            int main() {
                int age = 20;
                int hasID = 1;
                if (age >= 18){
                    if(hasID == 1){
                        printf("Entry allowed");
                    } else {
                        printf("ID required");
                    }
                } else {
                    printf("Entry not allowed");
                }
                return 0;
            }

Output:

Entry allowed

6. The switch Statement

The switch statement is used to select one block of code from multiple possible options.

Syntax:


            switch(expression){
                case value1:
                    //Code
                    break;
                case value2:
                    //Code
                    break;
                default:
                    //Default Code
            }

Example:


            #include <stdio.h>
            int main() {
            int choice = 2;
            switch (choice) {
                case 1:
                    printf("Home");
                    break;
                case 2:
                    printf("Profile");
                    break;
                case 3:
                    printf("Settings");
                    break;
                default:
                    printf("Invalid choice");
                }
                return 0;
            }

Output:

Profile

The break statement exits the switch block. Without it, execution can continue into the next case. The default block executes when no case matches.

7. Difference Between if-else and switch

  • if-else: Useful for checking ranges, comparisons and complex conditions.
  • switch: Useful for selecting between specific constant values.
